# Código de conducta / Code of Conduct

Esperamos una colaboración respetuosa, clara y constructiva. No se toleran
acoso, ataques personales, discriminación, publicación de datos privados ni
reportes deliberadamente engañosos.

We expect respectful, clear, and constructive collaboration. Harassment,
personal attacks, discrimination, private-data disclosure, and deliberately
misleading reports are not acceptable.

Los mantenedores pueden retirar comentarios o contribuciones que incumplan
estas reglas.

Maintainers may remove comments or contributions that violate these rules.
